# TweenSlop Studio

Локальный браузерный мини-редактор вертикальных роликов: Python здесь раздаёт приложение и сохраняет монтаж, а интерфейс и предпросмотр сделаны на HTML/CSS/JavaScript. Зависимости Python не нужны.

> Это оригинальный редактор с привычными функциями видеомонтажа, а не копия интерфейса, кода, бренда или платных материалов Alight Motion. Добавляйте только медиа, на которые у вас есть права.

## Запуск

```bash
python app.py
```

Откройте `http://localhost:8000`. Можно указать порт: `python app.py --port 8080`. Браузер хранит исходные медиа в IndexedDB на этом устройстве; таймлайн и настройки проекта сохраняются также в `data/project.json`.

## Что умеет прототип

- Импорт видео, изображений и аудио, добавление слоёв на многодорожечный таймлайн.
- Предпросмотр композиции, перемещение клипов, обрезка ручками, разделение, дублирование и удаление; undo/redo.
- Форматы 9:16, 16:9, 1:1 и 4:5; текстовые слои, эмодзи-стикеры и простая анимация текста.
- Настройка масштаба, позиции, прозрачности, громкости и цветокоррекции.
- Эффект «Цветовой ключ» вырезает однотонный фон (например, зелёный экран). Это chroma key, а не AI-сегментация: на сложном/неоднородном фоне результат зависит от съёмки и порога.
- Экспорт композиции в WebM средствами браузера. Для длительного экспорта вкладку нужно оставить открытой.
- Плагины-эффекты и действия на JavaScript.

## Плагины

На вкладке **Плагины** можно подключить `.js`/`.mjs` модуль. Плагин должен экспортировать объект по умолчанию и вызвать `install(api)` либо объявить эффект/действие напрямую. Пример находится в `web/plugins/pulse-zoom.js`.

```js
export default {
  id: "my-tint",
  name: "Мой оттенок",
  description: "Лёгкий пример эффекта",
  type: "effect",
  defaults: { amount: 0.2 },
  controls: [
    { key: "amount", label: "Интенсивность", type: "range", min: 0, max: 1, step: 0.01, default: 0.2 }
  ],
  apply({ ctx, canvas, settings }) {
    const image = ctx.getImageData(0, 0, canvas.width, canvas.height);
    // Измените image.data и вызовите ctx.putImageData(image, 0, 0).
  }
};
```

API доступно плагину в `install(api)`: `api.registerEffect(effect)`, `api.registerAction(action)`, `api.addEffect(id)`, `api.addText(text)`, `api.getSelectedClip()` и `api.toast(message)`. Эффект может реализовать `apply({ctx, canvas, time, duration, settings, clip})`, `transformScale({time, settings})` и/или `overlay({ctx, width, height, time, settings})`. Для действия задайте `{ id, name, description, type: "action", run(api) { ... } }`.

JavaScript-плагины исполняются в контексте этой страницы. Загружайте только код, которому доверяете; экспериментальные плагины могут повесить вкладку или повредить текущий монтаж.

## Ограничения

Это компактный MVP, не замена профессиональной монтажной станции: экспорт сейчас WebM, нет автоматической AI-вырезки фона, облачной синхронизации и готовых лицензированных библиотек музыки/шрифтов. Исходные медиа не отправляются на сервер и не включаются в `data/project.json`; храните их отдельно и используйте правомерно.
